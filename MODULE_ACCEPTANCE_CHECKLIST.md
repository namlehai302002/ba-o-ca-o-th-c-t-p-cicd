# Module Acceptance Checklist

## Inbound

- [x] Tạo phiếu, duyệt, nhận, kiểm, putaway, post tồn.
- [ ] UAT bằng scanner thật.

## Outbound

- [x] Reservation, pick, pack, ship, chống xuất quá tồn.
- [ ] UAT giao hàng thật.

## Inventory

- [x] Tồn theo kho/vị trí/lot/serial/owner/hold status.
- [ ] Reconciliation với dữ liệu production thật.

## Users And Security

- [x] Admin, Manager, Staff, Viewer và scope.
- [ ] Ký nhận phân quyền của chủ hệ thống.

## Reports And Analytics

- [x] Tồn kho, nhập xuất tồn, audit, BI, predictive, SRE.
- [ ] Đối chiếu báo cáo với kế toán/ERP thật.

## Yard And Dock

- [x] Dock appointment, yard visit, evidence upload.
- [ ] Kiểm thử với cổng bãi thật.

## Carrier

- [x] Connector, callback, tracking, replay.
- [ ] Certified carrier sandbox/production.

## 3PL Billing

- [x] Contract, rate, run, invoice, dispute, export.
- [ ] Ký nhận hóa đơn với khách thuê kho thật.

## Mobile, RF And Offline

- [x] Mobile shell, offline queue, scan parser.
- [ ] RF scanner thật và mạng kho thật.

## Integration And API

- [x] OpenAPI, EDI, webhook, connector health.
- [ ] ERP/OMS/TMS certified integration.
